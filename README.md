# موقع O. Arabi

موقع ثابت (HTML/CSS/JS) من غير أي أدوات بناء، بيشتغل على GitHub Pages مباشرة.

## الهيكل
- `index.html` — الصفحة الوحيدة، والتنقل بين الصفحات بيتم جواها.
- `css/style.css` — الألوان في أول الملف (`--bg` و`--cream` و`--gold`).
- `js/data.js` — **كل المحتوى هنا**: المجموعات، الأعمال، الأسعار، الأسئلة، الآراء، روابط التواصل.
- `js/app.js` — منطق الموقع والأنيميشن.
- `js/local.js` — قائمة الصور الموجودة في فولدر `img/` (بتتولّد تلقائيًا).
- `img/` — صور الأعمال بعد الضغط (WebP).
- `assets/` — اللوجو والأيقونات.

## الصور والفيديوهات
- الصور اللي في `img/` بتتحمّل من الموقع نفسه.
- الفيديوهات وصور Lacoste وJushike وGhost Aura وPan Spoor واللوحات القديمة لسه بتتحمّل من موقعك القديم
  (`IMG_BASE` في أول `js/data.js`)، فمتمسحش الموقع القديم قبل ما تنقلها.

## إزاي ترفعه
ارفع كل محتويات الفولدر على ريبو GitHub واعمل Settings ← Pages.

## الصوت والإضافات
- `audio/ankabut.m4a` — التلاوة الخلفية. `js/audio.js` بيعرض شاشة اختيار (بصوت / بدون صوت) عند الدخول، وزرار ثابت تحت يمين للتحكم.
  الصوت بيقف لوحده لما تفتح تاب تاني أو تشغّل فيديو.
- `js/extras.js` + `css/extras.css` — إضاءة تتبع المؤشر، زوم وزرار "اطلب تصميم زي ده" في الـ lightbox،
  تلوين صفحة كل حملة بألوانها (من `story.palette`)، وحاسبة التكلفة في صفحة الخدمات (بتقرا الأسعار من `OA.packages`).
- `manifest.webmanifest` — عشان الموقع يتثبّت على الموبايل.
